# Projeto Integrado: Totem Social (DS + IA)

Este repositório contém a modelagem, scripts de criação, inserção de dados e consultas para o banco de dados do **Totem Social**.

## 📁 Estrutura do Repositório

* **`docs/`**: Documentação das regras de negócio e modelos relacionais.
* **`database/`**: Scripts SQL organizados:
  1. `script_ddl.sql`: Criação das tabelas e restrições.
  2. `script_seed.sql`: Povoamento com dados de teste.
  3. `script_dql.sql`: Consultas que respondem ao negócio.
* **`evidencias/`**: Comprovações da execução dos scripts.

## 🚀 Ordem de Execução dos Scripts

1. Executar `database/script_ddl.sql`
2. Executar `database/script_seed.sql`
3. Executar `database/script_dql.sql`
