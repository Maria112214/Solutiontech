# Regras de Negócio: Totem Social

1. **Vínculo de Ponto de Apoio:** Todo ponto de apoio deve pertencer obrigatoriamente a uma organização (ONG ou Prefeitura) responsável cadastrada.
2. **Atualização de Vagas:** As vagas ou quantidade de refeições dispostas em `ponto_servico` devem ser atualizadas diariamente pelas ONGs parceiras.
3. **Identificação Única dos Totens:** Cada totem físico deve ter um `codigo_totem` único para identificação no sistema.
4. **Visibilidade no Totem:** Apenas serviços com status operacional ativo e vagas/marmitas maiores que 0 serão destacados como prioridade de atendimento nas telas dos totens.
